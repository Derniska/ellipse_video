# ellipse_video
Видеоаналитика розничных магазинов косметики и парфюмерии: обработка видеопотоков, обнаружение и отслеживание людей, подсчёт посетителей и подготовка данных для анализа посещаемости и конверсии

---

## 📌 Описание проекта

Проект предназначен для интеллектуальной видеоаналитики в точках розничной торговли сети парфюмерии и косметики. Система решает задачи автоматизированного подсчёта входящего и выходящего потока посетителей, анализа трафика входной группы, а также подготовки структурированных данных для расчёта ключевых метрик магазина (посещаемость, конверсия, пиковые часы нагрузки).

---

## 🚀 Основные возможности

- **Детекция людей в кадре:** Использование современных легковесных моделей нейросетей семейства YOLO (`YOLOv8n`, `YOLO11n`, `YOLO12n`), оптимизированных для высокой скорости инференса в режиме реального времени.
- **Трекинг посетителей:** Присвоение и непрерывное удержание уникальных идентификаторов (ID) для каждого посетителя с использованием алгоритмов трекинга `BotSORT` и `ByteTrack`.
- **Подсчёт пересечений через виртуальную линию:** 
  - Реализация математического алгоритма определения положения точки (ног/центра человека) относительно произвольной ориентированной линии через знак косого (векторного) произведения.
  - Точный учёт направления движения (вход / выход) и защита от повторных срабатываний для одного и того же трека (`counted_ids`).
- **Оптимизация производительности (ROI):** 
  - Интерактивный выбор и вырезание зоны интереса (Region of Interest) на входе в магазин.
  - Обработка только ключевой области кадра с последующей проекцией координат на исходный видеопоток, что существенно снижает нагрузку на CPU/GPU.
  - Прореживание кадров (обработка каждого N-го кадра) для ускорения пайплайна.
- **Диагностика сетевого оборудования:** Проверка доступности портов, камер и серверов видеонаблюдения (например, TRASSIR / RTSP / HTTP) через роутеры и сетевые маршруты магазинов.
- **Работа с медиапотоками:** Поддержка локального набора утилит `FFmpeg` для нарезки, конвертации и склейки видеофайлов из архивов камер.

## 🧠 Принцип работы алгоритма подсчета

1. **Определение виртуальной линии:** Задаются две опорные точки линии $A(x_1, y_1)$ и $B(x_2, y_2)$, разграничивающие вход и внутреннее пространство магазина.
2. **Анализ положения объекта:** Для нижней центральной точки детекции человека $P(x, y)$ вычисляется знак ориентированной площади:
   $$D = (x_2 - x_1) \cdot (y - y_1) - (y_2 - y_1) \cdot (x - x_1)$$
   - $D > 0$: точка находится по одну сторону линии;
   - $D < 0$: точка находится по другую сторону линии;
   - $D = 0$: точка лежит строго на линии.
3. **Фиксация события пересечения:** При переходе знака $D$ с отрицательного на положительный фиксируется факт пересечения. Уникальный идентификатор трека заносится в `counted_ids`, исключая дублирование подсчёта одного и того же человека.
4. **ROI-фильтрация:** При анализе потоков высокого разрешения видеопоток кропается до прямоугольника прохода (`crop_frame`), обработка передается в нейросеть, а результаты отображаются с компенсацией смещения $(x + ROI\_X, y + ROI\_Y)$.
